Accessibility Statement

Last updated: 5 October 2026

I want everyone to be able to use this website, including people who use screen readers, keyboards, magnification or voice control.

1. The standard

This website aims to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

2. What's been done

  • Text and buttons have strong colour contrast (at least 4.5:1, and much higher for body text).
  • Everything works with a keyboard. Focus is clearly visible, and a “Skip to main content” link comes first.
  • Pages use clear headings and landmarks, so they're easy to navigate with a screen reader.
  • The order planner has visible labels, plain-English error messages linked to each field and a summary of any problems.
  • Buttons and links have clear labels, and links that open in a new tab say so.
  • Decorative drawings are hidden from screen readers.
  • The site works when zoomed to 400% and on screens as narrow as 320 pixels, without sideways scrolling.
  • Animations are turned off if your device is set to reduce motion.
  • The site works without JavaScript, except the order planner. You can still order by sending the details listed in “How to order”.

3. Known limitations

  • Orders are placed through Instagram, which is run by Meta. I can't control how accessible Instagram is.
  • Photos of my bakes are on Instagram rather than on this website.

4. Feedback

If you find a problem, or need information in a different format, please send me an Instagram message to @cakedbyabbie (opens in a new tab). Tell me the page and what went wrong, and I'll do my best to fix it.

This statement was prepared on 5 October 2026.
